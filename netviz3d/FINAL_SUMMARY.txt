## 🚀 3 Simple Steps to Deploy

### Step 1: GitHub (10 min)
```bash
cd netviz3d
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/YOUR_USERNAME/netviz3d.git
git branch -M main
git push -u origin main
```

### Step 2: Render Backend (10 min)
1. Go to render.com
2. Connect GitHub repository
3. Create Web Service (name: `netviz3d-backend`)
4. Deploy ✓

### Step 3: Vercel Frontend (10 min)
1. Go to vercel.com
2. Import from GitHub
3. Add `VITE_API_BASE` env var
4. Deploy ✓

**Total: ~40 minutes to live!** 🎉

## 🔐 Important Security Notes

1. **Never commit `.env` file**
   - Use `.env.example` as template
   - Set actual values in service dashboards

2. **Keep API keys secret**
   - Only in environment variables
   - Never in code

3. **Use HTTPS everywhere**
   - Both Render and Vercel provide HTTPS
   - All communication encrypted

4. **Limit API access**
   - Set CORS restrictions (if needed)
   - Monitor API usage
